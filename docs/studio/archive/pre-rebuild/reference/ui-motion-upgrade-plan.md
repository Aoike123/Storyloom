## 二、动效系统（全项目统一）

气质基调沿用现有选择页：**安静、轻盈、有呼吸感**；动效 = 反馈与连续，不做装饰。静态截图与今天基本一致，差异只在"操作过程中"。

### 2.1 时长与曲线 token（写入 `app/globals.css`，全组件引用）

```css
:root{
  --motion-tap:   90ms;   /* 按下/抬起 */
  --motion-hover: 160ms;  /* 悬停、选中底色、边框 */
  --motion-soft:  200ms;  /* 内容更新、淡入淡出、重排 */
  --motion-slow:  240ms;  /* 面板开合、页面/阶段切换 */
  --ease-out:    cubic-bezier(.22,1,.36,1);  /* 现有封面卡组曲线，升格为全局标准 */
  --ease-settle: cubic-bezier(.33,.84,.3,1); /* 面板开合、滚动 */
}
```

### 2.2 硬性规则

- 只用 `opacity` 与 `transform`（合成器友好）；需要尺寸变化的场合用 `grid-template-rows: 0fr → 1fr` 或 FLIP，不用动画读写布局。
- 同一时刻一个区域只有一种等待动效（进度条 **或** 阶段文字 **或** 图标三选一），禁止 spinner + 跑动条 + 打字机同屏。
- 位移上限 8px，缩放上限 1.015；不用弹簧、弹跳、全页模糊、长距离滑动。
- 连续快速操作以最新为准，取消旧过渡，不排队。
- `prefers-reduced-motion: reduce` 时取消位移/缩放/环境循环，保留即时状态反馈（现有 `.reader-world` 块扩展为全局）。
- 关键消息（错误、结论、选中态）一次性完整显示，不逐字；打字机只允许用于**首次返回的非关键说明**，且容器预占完整文字高度（不让按钮被顶动）。

### 2.3 新增"氛围层"（本次"动效感"的主要来源）

页面不静止，但任何时刻没有一件在"表演"：

- **封面卡组呼吸**：当前封面 8s 循环 1.000→1.012 缩放 + 背后光晕 20s 缓慢漂移。**实现注意**：缩放必须作用于卡片**内部的 img**（`.reader-cover-visual` 的 transform 已被 hover/focus 的 transition 占用，直接叠加 keyframes 动画会与其互相覆盖——动画运行期间 transition 失效，悬停抬起会被吞掉）；img 在 `overflow:hidden` 容器内缩放，无布局影响。光晕只动 `.reader-cover-visual:before` 的 opacity（该属性无冲突）。
- **一次性入场编队**：页头 kicker/标题/按钮按 60ms 间隔依次淡入 + 8px 上移，仅在首次渲染播放；滚动进入视口的网格卡片/阶段模块用 `IntersectionObserver` 一次性 200ms 入场（新增 `useReveal` hook，只触发一次）。
- **活体进度**：活跃任务行背景做 4s 极慢的明暗呼吸（2% 振幅），传达"机器在动"，不抖、不转。

## 三、分阶段实施（每阶段独立可交付、可回滚）

### 阶段 0 — 修复解耦破坏（功能与文案，动效最小）

1. **移除模型调用许可勾选框**（已确认 A1）：
   - 删除 `useModelPermission` 的勾选框 UI（`studio-paid`、AssetFeedback/AssetRedesign 卡片内的许可行）；前端所有生成动作继续发送 `confirm_paid: true`——**按钮点击本身即确认**，API 契约不变，422 不会发生。
   - 后端 5 处 422 防御性文案统一为"请确认开始本次生成"风格（正常路径不会触发——前端总是带确认字段点击即发）；其中 production.py:92 的"请确认视频生成费用。"是**必改**（计费措辞漏网）；reader_branch.py 的 `confirm_generation` 字段名保留不改（避免动读者侧契约），仅统一文案。
   - 替代物：**只读模型状态**。新增 `GET /api/models`（裁剪返回 `{llm/image/video_configured, models, config_file}`，**不直出 `providers.settings()` 的 `editable` 全量配置**——虽不含密钥，但没有必要）；作者台页头加一枚安静的状态签（三行小字：文本/画面/视频 模型已就绪·绿点 / 未配置·灰点 + "在 .env.local 里填写"）。
   - **不预禁用按钮**：动作→模型种类的映射复杂（风格推荐=llm、准备形象=image、分镜=llm、漫剧生成=video、继续下一集=llm+video），误判会阻断合法流程。后端 `reserve_call`/`paid_gate` 已有逐类拒绝文案链（"尚未配置该模型的完整 API 信息"），失败时原样透出即可；状态签负责事前提示，报错负责事后解释。
2. **读者空态统一**：
   - 0 故事 → 页头变为邀请态：标题"把你脑子里的微小说，搬进来。" + 主按钮"导入第一篇微小说"（点击即开面板），移除"重试读取目录"空舞台；网格空态保留导入按钮作为第二入口。
   - 有故事但 0 可放映 → 沿用现文案（"切到「等待创作」…"）。
3. **导入面板动效与状态管理**：开合 240ms（`--ease-settle`）淡入 + 8px 上移 + 高度 0fr→1fr 推开书架（书架下移随高度自然发生，不再跳）；"导入故事"按钮内 Plus 图标 160ms 旋转 45° 变"收起"；错误/成功行 200ms 淡入；导入成功后新卡片 200ms 淡入 + 4px 上移入场，面板展示成功态 1.2s 后自动收起。**草稿保留**：面板内容（标题/正文/文件/错误）提升到父组件 state 或 sessionStorage——当前关掉面板即全部丢失。**焦点管理**：打开时焦点移入面板第一个输入框，关闭时还原到"导入故事"按钮（与现有 `data-reader-focus` 恢复机制一致）。`catalog-warning` 横幅（内容过期/读取失败）出现/消失同用 0fr→1fr，不再硬插。
4. **工具栏再平衡 + 按钮样式修复**（对应诊断 #4/#9）：
   - `.catalog-import` 按上下文拆权重（修根因 d）：工具栏内降为次级幽灵样式（细边 `1px #ffffff2a`、透明底、`#c9dfab` 文字，hover 轻微提亮）；空态内保持实心主按钮，并显式锁定深色文字（`.reader-empty .catalog-import{color:#1c3022}`，压过 `.reader-empty button` 的覆盖——修真凶 a）。
   - `.catalog-refresh` 控件化：补 padding/圆角/hover 底色，从裸文字变成可感知的按钮。
   - `.story-import-actions .button.primary:hover:not(:disabled)` 补 hover 提亮（`#d7eaba`）；`:disabled` 的 `cursor:wait` 改 `not-allowed`。
   - 布局：筛选组 + 搜索为一组（左），刷新 + 导入为一组（右）；筛选选中底色 160ms 滑动。

### 阶段 1 — 读者连续性（"接得上"）

1. **进入/返回放映页**：进入 220ms 淡入 + 6px 上移（内容区），顶栏稳定不闪；返回时恢复筛选/搜索/滚动位置/键盘焦点（基于现有 browse 状态）+ 200ms 淡入。共享元素封面过渡列为第二轮可选（需真实页面验证坐标与回退，不阻塞本阶段）。
2. **筛选/搜索重排——补齐离场**：`ReaderStoryGrid` **已实现 FLIP**（保留卡片 200ms 位移 + 新卡 180ms 淡入上移，且处理了 `reducedMotion` 与动画取消），缺口只有**离场**——被筛掉的卡片因 React 直接卸载而瞬间消失。补法：离场卡片延迟卸载 160ms（父组件维护 pending-exit 集合，淡出后真正移除）。顺手把曲线统一到 token：现状 move 用 `cubic-bezier(.2,.7,.2,1)`、enter 用 `ease-out`、封面卡组用 `cubic-bezier(.22,1,.36,1)`，三处不一致。
3. **换段交接（修 #6）**：换段前保持当前帧；利用已有 `reader-video-preload` 元素做交接——下一段首帧可解码后再 180ms 交叉淡化切换，旧播放器随后卸载；严格同时只有一个元素出声；音量/静音/播放意图/累计时间保持；播放按钮 90ms 按压态且"播放意图"延续到媒体就绪（不假装立刻出画）。
4. **互动区（脑洞/分支）**：视频暂停时输入框焦点环做一次 2s 温和提示（不重排布局）；分支规划中沿用单模式等待；分支就绪 180ms 勾选 + 淡入滑出状态条；失败保留草稿、错误原位显示。
5. **打字机约束**：`StreamText` 仅限首次返回的非关键说明；结果性文字一次到位。

### 阶段 2 — 作者台连续性（"稳"）

1. **阶段切换**：阶段模块 220ms 淡入 + 6px 上移；步骤条激活标记 160ms 滑动到新阶段；仅用户刚点"下一步"时才平滑滚动到新阶段标题，后台更新只亮状态、不抢焦点。
2. **等待单模式**：活跃任务只显示进度条（有值）或阶段文字（无值）之一 + 活体呼吸背景；完成项一次性 180ms 勾选后安静；`InteractionFeedback` 固定最小高度，出现/消失不再推挤按钮。
3. **跟随控制**："回到正在制作" 240ms 平滑滚动（`--ease-settle`），目标模块收到一次柔和高亮（1s 淡出）；滚动页面暂停跟随的提示保持原位。
4. **展开/收起**：任务详情、尝试历史 200ms `0fr→1fr` 展开，标题与操作入口稳定不移动。
5. **素材网格**：图片在固定画幅容器内 160ms 淡入（错误时原位显示重试，不塌陷）；新版本替换旧素材 220ms 交叉淡化；发布时刻 = 一次性 180ms 勾选 + 卡片一次柔和辉光 + "观看这部漫剧" 淡入滑出（不用彩带等闹场元素）。

### 阶段 3 — 打磨与验收

- 真实页面测量：对同一流程做操作前后 performance 录制（触发器、渲染耗时、原因），统一微调时长（上表为设计初值）。
- **性能预算**：动画期间无线程级长任务（>50ms）；点击→首帧反馈 <100ms；重排/FLIP 保持 60fps；`useReveal` 的 observer 触发后即 unobserve。
- reduced-motion 全链路走查（桌面/触屏/键盘三端各跑一遍读者流程与作者流程）；**新增 hover 动效一律包在 `@media (hover: hover)`**（沿用 reader-motion.css:35 的既有约定，避免触屏粘滞态）。
- 测试随阶段更新，不积压到本阶段：**阶段 0 即需改写 `web/tests/asset-feedback.test.cjs`**（它断言了许可勾选框文案，是全仓唯一受勾选框删除影响的测试；后端无测试断言 422 文案，改文案零测试成本）；阶段 1 补面板开合/空态邀请/模型状态签用例；`next build` 通过且产物不含被删概念。
- 旧方案文档标记"已并入本计划"（已完成）。
