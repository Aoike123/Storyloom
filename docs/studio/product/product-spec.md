# 来源工作台产品规范

版本：2.0 · 2026-10-04。性质：**当前产品行为的唯一规范**。本版合并已确认的来源交互、制作、资产、成片与项目入口规则，替代归档方向稿和旧规范。设计确认不代表应用实现；进度见[验收账本](../execution/acceptance-ledger.json)。

布局参考[交互稿](../prototypes/source-studio.html)，工程定义见[领域契约](../architecture/domain-contracts.md)。下列 R 编号用于任务和验收追溯，编号保持稳定。

## R01 项目与创作路径

一个故事项目包含原文、故事片段、剧本、场与镜头、共用资产、制作任务、剪辑及发布版本。短篇和长篇使用同一模型；一次任务的预算不等于整部作品的长度限制。

路径：新建项目 → 添加原文 → 划选并确认片段 → 编写/采用剧本 → 分镜与资产准备 → 生成并审看视频 → 选用资源剪辑 → 确认剪辑版本 → 发布/导出。用户可返回已有对象，保存、确认、生成、采用和发布是不同动作。

先建立空项目，再在项目内添加原文。普通浏览、选择、导入和查看现有结果不会触发收费生成。

## R02 工作区与布局

项目顶栏展示项目身份、工作区切换和任务入口。左侧故事来源区贯穿工作台；主工作区处理当前任务；对象属性按需展开；每一步底部都有自然语言对话入口。

| 职责 | 主工作区 | 来源区如何参与 |
| --- | --- | --- |
| 切分/裁减 | 无限画布，处理真实片段、范围与节奏 | 连续阅读、划选、定位与来源对照 |
| 剧本 | 无限画布，编辑动作、对白等真实对象 | 整块荧光区域连到对应剧本对象 |
| 分镜 | 无限画布，组织场/镜头、规格、输入与衔接 | 返回片段及准确依据 |
| 资产 | 无限画布，人物、服装、场景等项目资产 | 原文实际出现位置连到具体资产及版本 |
| 成片 | 剪辑组件铺满主工作区 | 来源/片段列表同时作为实际视频资源区 |

五种职责用于当前任务上下文；标签文案与细微层级可以优化，不让后台阶段决定导航。无限画布中的对象均可自由拖动，空白区可平移，视野可缩放；卡片坐标不改业务归属、正式顺序或引用版本。

成片工作区承载时间轴、监看和编辑控件，属性按需展开或覆盖。空间不足时调整阅读区或面板，不在剪辑组件中间再增加第二个资源栏。

## R03 连续原文与动态片段

来源区有两种视图：

- **原文**：保留正文自身段落与换行，连续展示全文。行长、字体、行距和留白服务于阅读；片段以荧光笔涂色表达，不插片段卡片、标题、编号、状态或分隔线。
- **故事片段**：根据用户/AI 实际建立的片段动态生成名称、摘要和真实状态，默认按来源顺序组织。创建、拆合、改名和边界调整后同步更新；每项可点击定位。

两种视图共用同一正文版本、稳定片段身份及来源范围；切换保持阅读位置。未分配文字始终可读可划选。前台“原文”是全文来源视图名称，导入原稿保留为不可变历史依据；修改当前正文形成新版本，不另设第二个常驻稿件栏。

## R04 荧光区域与新建片段

**一个连续、非空的荧光区域就是一个故事片段。** 区域可以跨原生段落；一个片段不由数块离散涂色拼成。

| 操作 | 结果 |
| --- | --- |
| 在未分配文字中划选 | 形成临时连续选区，可明确新建候选或取消 |
| 新建候选 | 校验后持久保存，获得真实片段身份，列表/高亮/画布同步 |
| 确认候选 | 确认该片段的当前版本，后续制作可以采用；不自动生成 |
| 点击已有高亮或片段项 | 定位并恢复上下文，不新建、不确认、不生成 |
| 取消临时选区 | 撤销临时状态，不删除已保存候选 |

已保存候选和已确认片段共同参与范围校验：重复、部分相交、包含与被包含均冲突，边界相接允许。冲突说明具体已有片段并提供定位；不静默裁掉重叠文字、不覆盖或偷合并已有区域。空白、空范围、越界与非连续选择不建立片段。

AI 的片段提案执行同样规则。逐个候选允许正文尚未全覆盖；提交完整制作范围是另一项明确操作，单独显示顺序、覆盖、裁减及范围外内容。

## R05 来源连线

剧本动作/对白共同来源于一整块片段高亮：**从实际涂色边缘的一个点发出一条主干，再分支到多个对象。** 多行区域仍只有一个起点；不能从左侧栏边界、没有涂色的包围盒空白或多个零散词语分别发线。

滚动、换行、栏宽变化、节点拖动和画布缩放后连线跟随。区域离屏时提供返回来源入口，不画悬空线。当前关系按所选片段/对象局部展开，避免累积整个项目的关系网。

资产页从原文实际出现位置关联项目中的真实资产及准确版本。一个资产可在多个片段出现；出现是出处关系，不是资产归属，也不因此复制资产。镜头资产输入另按用途、作用对象与版本记录。

## R06 归属、选择与恢复

对象有唯一真实归属；镜头属于一场，服装属于人物身份，资产在项目内共用。版本、出处、任务和使用关系不创建第二套可写归属树。提示词与计算阶段不成为项目层级。

属性面板对应实际选中的对象，展示身份、真实父级、来源、版本、状态及可编辑字段。成片选中的是独立剪辑实例；资源选择和时间轴实例选择分别管理。没有选择时给准确空态，不显示静态任务介绍充当属性。

制作中点击片段恢复该片段的步骤、对象及画布视野；资产恢复项目共用上下文。成片中的来源点击只浏览资源，保留当前项目时间轴。刷新、返回、改名和切换项目按稳定身份恢复；目标已退役/合并时说明并定位有效上下文。

## R07 剧本、分镜与共用资产

剧本记录片段中的动作、对白、出处与改编内容，编辑草稿和采用版本分别保存。分镜记录实际场、镜头顺序、画面/动作/对白、衔接及固定输入；自由拖动不修改镜头顺序，重排需要明确命令。

| 资产 | 规则 |
| --- | --- |
| 人物身份 | 稳定身份与外貌规格；改名、换衣、跨片段使用不新建身份 |
| 服装 | 独立规格和版本，归属具体人物；同一镜头中的同一人物不能同时绑定两套服装 |
| 物理场景 | 稳定空间与版本，区别于叙事中的“场” |
| 自然体表角色 | 可明确无需服装，不用空图冒充已生成服装 |

项目内跨场复用是本轮要求。引用固定具体版本；生成/上传形成可检查的新版本。确认新版本不让所有场自动采用，采用需指定范围并预览影响，已发布快照不变。

资产详情可查看真实媒体、规格、身份/服装关系、并存版本和准确使用位置。分镜/视频生成前检查采用剧本、必要资产和人工审核的具体版本；结构校验、AI预审、任务完成与作者确认分别表达。

## R08 任务与人工审核

任务属于项目，提交时冻结片段范围、目标对象、输入版本与依据。切换片段、工作区或关闭页面不取消、重启或重新归属已有任务；结果回到原目标，完成不抢焦点。项目队列可定位原工作位置、查看结果与处理具体失败。

排队、执行、待审核、完成、失败、取消和已被取代依据真实记录显示，不能从当前标签或阶段编号推断。供应商接收不等于完成，完成不等于作者审核，审核不等于采用或发布。

生成前展示实际范围、必要输入和可提供的成本信息；未知费用说明未知。重试先检查原请求结果，重做冻结新输入；不把失败恢复和整轮重做放在同一含糊动作里。

审核针对对象的准确版本及依赖。主按钮就是明确确认动作，不要求再勾“我已看过全部内容”；多选范围也不自动确认后代。阻塞操作旁给具体缺少条件与修复入口。

## R09 成片资源与编辑

左侧来源列表按片段/镜头/视频版本组织实际可用资源。片段候选、文字摘要或缺媒体对象不能冒充视频。点击资源浏览/预览；**明确插入**才创建时间轴实例，不跳去剧本、不清空时间轴。

同一视频可多次使用，每次有独立实例身份，固定片段、来源正文、镜头、视频版本与选用区间。重排、裁切、速度、声画参数和删除只改该实例，不能反写源镜头、删除源视频或修改另一实例。

项目剪辑草稿可保存恢复；切片段、切标签、返回与刷新不丢失已保存编辑。监看基于实际媒体和编辑数据，时长/切点来自真实资源；支持范围由内核决定，不展示不可用的假效果。

剪辑确认形成不可变版本；预览、导出、发布采用同一编辑依据与输出规格。修改草稿不改旧发布，导出失败可同版重试，无需重新生成镜头。

## R10 每步骤自然语言对话

切分、剧本、分镜、资产、成片均有工作区底部对话框，可以自由提问；入口固定在界面层，不随画布缩放，不要求标出agent、模型或角色名称。

发送时冻结项目、步骤、片段、所选对象/版本及相关范围。切换后恢复对应历史和未发送输入，后台回答归原会话，不替换当前上下文或抢焦点。

回答可以读取范围内真实状态/出处，修改建议作为结构化提案。用户明确采用后再校验版本、范围和影响，调用正式命令；回答本身不保存业务、不确认、不收费生成、不发布。

## R11 修改、版本与影响

正文、片段边界、拆合、剧本、场/镜头、资产或视觉方向变更，先预览准确依赖、需人工复核的叙事影响与可保留产物，再明确应用。无法确定的后续影响标为需复核，不承诺“只影响当前片段”。

正文创建新版本；原范围不能直接套到新文本。片段改名保持身份，边界变更保存版本，拆合保存继承与旧依据。任务继续使用发起时输入，迟到结果保留在原版本记录中，不能覆盖当前采用结果。

失效标记与物理删除分别处理。新系统产生的视频、剪辑和历史发布始终可追溯实际输入；本轮旧代码退役不自动清空存储，也不安排旧格式迁移或兼容。

## R12 项目入口与公开边界

首页按公开项目展示封面、名称、创作者、简介与已发布成片；一个项目多个成片仍归同一项目。顶栏提供新建项目、我的项目、搜索和主题入口。公开列表为空与用户没有个人项目分别表达，空状态仍能新建。

先建项目再添加原文。未登录的新建意图可以在登录后继续，不从点击公开卡片隐式创建。个人项目按账号归属隔离；公开详情与观看使用显式公开的发布内容。

公开发布不默认公开原文、剧本、过程资产或私有对话。付费/运营后台、跨项目共享库与读者实时改写不并入本轮已承诺闭环；需要独立定稿和任务，不从旧文档自动恢复。

## R13 视觉与可操作性

阅读区保持安静、连续和清晰的荧光标记；制作区用留白与轻边界组织对象，减少层层套框。来源区宽度、字体与高亮色按已确认稿逐步优化，不恢复常驻完整目录、第二套场选择器或独立版本导航。

明暗主题共享语义色、控件几何与状态表达，主题偏好可恢复。选中、待审核、已确认和失败都有文字/图标，不只靠颜色。统一主/次/文字/危险操作与表单标签，缺少条件和错误给可恢复说明。

主要触控目标至少44px；键盘能选择、划选、确认、取消和使用关键命令。窄屏采用可收起来源、按需属性与等价命令；不要求触屏拖动完成全部编辑。减弱动效设置有效；1440/1280桌面、800窄屏与390手机策略由真实页面验收。

## 范围与验收

本轮交付上述闭环，详细前后端目录、数据和命令由架构文档落实。可选篇章/集、跨项目素材推荐、运营扣费、读者改写及额外剪辑效果在需求定稿后另建任务，不让执行器根据历史草案扩展范围。

实现必须通过数据/并发、连续浏览器操作、任务/对话、媒体一致性、设计/操作和旧代码清除六项门槛，详见[GATE任务卡](../execution/tasks/10-gates.md)。文字更新、构建通过、画面相似或禁用占位按钮均不足以判定业务完成。
