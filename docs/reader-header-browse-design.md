# 读者主页页头定稿：随手翻翻

状态：方案 A 已实施。页头沿用用户选定文案；现已修正封面展开、堆叠层级和未生成漫剧的灰态。

## 目标与范围

沿用当前绿色、字体气质与故事目录，仅调整原大标语所在的页头。吸引力来自真实故事封面的探索、清晰的操作反馈和自然的内容发现。不增加独立游戏、不透露剧情，也不自动叠加未选的动态封面方案 D。

## 页头内容

- 主文案（用户已选定）：**这段脑洞，换你会怎么演？**
- 文案体现脑洞故事与读者参与，不承诺当前已具备实时生成改写视频的能力；不加入剧情线索或剧透。
- 文案使用约 26–32px 的常规页面标题尺度，保留现有字体气质；取消原英文宣传语及占据首屏的大标语。
- 页头展示最多三部真实故事：封面、标题、原始题材标签（最多两项）、内容状态。数据不够时按实际数量展示，不重复凑满。
- 已发布且可播放作品优先，入口为“观看漫剧”；其他作品沿用现有“原文与制作”入口，不能用观看按钮将用户引入制作页。
- 与下方图集共用可播放状态判断。未生成漫剧的封面保持灰态和较低图片亮度，显示“待生成漫剧”；悬停与选中也不恢复彩色。
- 不展示剧情摘要、角色秘密、关键物品、选项题或结局。封面本身也需要检查是否泄露关键内容。
- 优先使用已有封面；缺少封面时沿用现有文字封面方式，不临时捏造作品画面。

## 桌面构图

页头内左侧是一句简短邀请，右侧是最多三张有少量错位的封面。封面作为主体，装饰减少。页头目标高度约 280–340px，使下方原故事目录尽早进入视野；以真实长标题、实际封面比例和常用笔记本尺寸校验。

封面采用固定尺寸的舞台容器；原目录网格保持现有布局。封面错位只作用于页头，不修改下面的卡片体系。首张默认呈现完整标题和题材，其他卡片保留足够宽的可识别区域。

实现上以同一个选中状态决定鼠标、键盘和堆叠层级，选中卡片始终位于最前。链接点击区域固定，只对内部封面画面上移 20px 并轻微放大，避免边缘反复失去悬停。非选中卡片按与当前卡片的距离依次排在后方；桌面抬起产生的少量溢出不视为手机横向滑轨。

## 交互规则

| 操作 | 页面反馈 |
| --- | --- |
| 鼠标移到一张封面 | 该封面在约 180–220ms 内轻移到前景，其他封面少量让位，标题、题材和内容入口清晰呈现 |
| 快速移向另一张 | 直接朝最新目标过渡，取消旧动画，不排队、不弹跳 |
| 鼠标离开整个封面区 | 保留最后浏览的那张，避免立刻收回造成反复晃动 |
| 键盘 Tab 聚焦 | 获得与悬停相同的呈现与明确焦点；Enter 直接打开对应内容 |
| 点击封面或入口 | 一次点击进入对应作品，不先翻面再要求第二次点击 |
| 从作品返回 | 恢复页头最后浏览项、目录位置和已有筛选 |

不做自动轮播、整张卡片 3D 翻转、持续漂浮、拖动门槛或抽卡动画。细节先以封面位置与层级变化表达探索感。

只对透明度和位移做短过渡；避免通过扩大容器高度或卡片宽度推挤页面。题材与入口不被遮挡，卡片的点击区域稳定。减少动态效果时直接切换前景与选中样式。

## 手机呈现

页头改为一句邀请加紧凑封面列，露出下一张的一部分。可以横向轻扫浏览，也提供有文字标签的前后切换控件；实际卡片内容与入口不依赖 hover。点击即进入，不设计“第一下展开、第二下打开”的不明确行为。

没有横向内容时不显示切换控件。保留纵向页面滚动，不拦截普通上下滑动。按钮触控区域与卡片边缘不重叠。

## 状态与边界

- 首次加载：保留封面舞台尺寸，按最终比例显示占位；完成后短淡入，不把下方目录推走。
- 封面加载失败：原位置替换为文字封面，标题与入口继续可用。
- 目录有缓存：先呈现已知作品；后台更新不突然重排正在浏览的封面。
- 没有可用目录：显示简短空状态与重试，不编造推荐或作品数量。
- 无视频作品：明确“原文与制作”，沿用现有原文展示与制作入口；本轮不新增独立阅读页面，不暗示已有可播放视频。
- 全部交互保持免登录浏览；不触发生成、付费或发布。

## 验收重点

1. 第一眼能看清可浏览的作品与下一步动作，标题没有压过封面。
2. 快速悬停、点击、返回后没有动画排队、卡片闪动、遮挡按钮或状态错位。
3. 页头展开不改变文档高度，下方目录不被推挤。
4. 键盘、触屏和减少动态效果模式都能直接打开作品。
5. 不需要阅读玩法说明；没有题目、输赢、解谜或剧情预告。
6. 选中的是 A，动态视频预览不是本轮默认范围。
