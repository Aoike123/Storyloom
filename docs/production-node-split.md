# 制作节点拆分与直接参考图流程

此前的三步界面简化已回退，逐字输出修复保留。AI 定装融合和试拍均从新流程移除；超出接口图片数量时，只使用确定性的本地图像拼接。

## 当前流程

基础素材确认 → 分镜生成 → 漫剧生成 → 审片发布。

- **分镜生成**：先由 `story_segments` 把选定的微小说按原文编号切成连续、有序、互不重叠的片段，再逐片段调用 `storyboard` 编写参考图组合分镜与镜头提示词，合并成整片分镜后完成文本预审。
- **漫剧生成**：把分镜绑定的已审核参考图连同构图与运动说明直接交给参考视频模型，独立保存任务、输出和错误。

这两个制作节点是独立的持久任务。后一个节点只能使用前一个节点已保存的结果；失败停在当前节点，上游结果保留。当前工作流版本为 `author-brainstorm-v7`。

分镜不再一次性生成整篇。`story_segments` 只调用一次，输出每个片段的原文编号范围、剧情功能、出场人物、场景、镜头上限和结尾状态；`storyboard` 随后一个片段调用一次，每次只收到本片段原文，片段内从 S01 编号。调用方按片段顺序合并、统一重编整片镜号，在片段首镜写入“承接上一片段”并补齐跨片段的 setup_ids，最后对整篇再做结构与素材校验。片段切割结果保存在导演方案里，作者可以在制作页展开查看；已通过校验的片段分镜会写入 `board_progress`，服务重启或恢复时按片段复用，只有失败的片段会重新请求模型。

当前节点或其子任务报错时，制作页直接提供“重新运行当前节点”。该操作建立新的节点任务，不复用旧失败缓存；旧任务、诊断和已完成素材保留，并把上一次具体错误交给新的分镜模型作为修正规则。另保留“继续当前节点”用于能够安全复用已保存输出的恢复场景。

## 参考图约束

每张服装图必须绑定正确的人物身份。分镜模型先输出完整的语义绑定，不能为接口限制省略人物、服装或场景。参考视频模型每镜最多使用九张图片：分镜把该镜所需的身份图、对应服装图和一张场景图原样附加。只有完整绑定超过九张时，调用方才用本地图像工具把同一角色的身份图与服装图左右并排成一张参考板（不调用任何生图或改图接口，源图不变），拼接后仍超九张的多人内容才通过反打、近景或空场景拆镜。流程不再生成镜头参考图。人物身份图上的基础服装不作为最终衣着。提示词只按用途点名项目参考图，不写版式或防合并说明。

已生成的 AI 定装和试拍图片保留为历史。新流程不创建这些生成任务；条件拼接不调用模型，并保存人物、服装及其版本依赖。尚未提交的旧任务在接管时停止排队，已经提交的请求不自动重发。旧版流程代码只保留兼容用途。

## 卡片与提示词

素材卡片按各自内容高度排列。提示词默认折叠，同一排只展开一个；长内容在限制高度的区域内滚动，复制入口保留，不再将整排卡片拉成长条。

本轮仅针对主流程、人物与服装绑定、类型和卡片展开做必要检查，没有为验收新增付费生成。
