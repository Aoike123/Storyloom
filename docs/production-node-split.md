# 制作节点拆分与直接参考图流程

此前的三步界面简化已回退，逐字输出修复保留。根据后续要求，定装合成和试拍均从新流程移除。

## 当前流程

基础素材确认 → 分镜生成 → 漫剧生成 → 审片发布。

- **分镜生成**：直接绑定已确认的人物身份图、独立服装图与场景图，编写参考图组合分镜和镜头提示词，完成文本预审。
- **漫剧生成**：根据分镜生成镜头参考图及视频片段，独立保存任务、输出和错误。

这两个制作节点是独立的持久任务。后一个节点只能使用前一个节点已保存的结果；失败停在当前节点，上游结果保留。当前工作流版本为 `author-brainstorm-v6`。

## 参考图约束

每张服装图必须绑定正确的人物身份。当前镜头参考图模型最多使用三张图片；含指定人物的镜头使用人物身份、对应服装、场景各一张，复杂多人内容通过拆镜安排，不省略必要参考图。人物身份图上的基础服装不作为最终衣着。

已生成的定装和试拍图片保留为历史。新流程不创建这些任务；尚未提交的旧任务在接管时停止排队，已经提交的请求不自动重发。旧版流程代码只保留兼容用途。

## 卡片与提示词

素材卡片按各自内容高度排列。提示词默认折叠，同一排只展开一个；长内容在限制高度的区域内滚动，复制入口保留，不再将整排卡片拉成长条。

本轮仅针对主流程、人物与服装绑定、类型和卡片展开做必要检查，没有为验收新增付费生成。
