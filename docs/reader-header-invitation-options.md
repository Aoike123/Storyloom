# 页头：吸引力与探索感候选

当前范围：继续设计，尚未实施。保留现有选择页的视觉风格与故事目录，优化页头内容、轻交互及动效。独立小游戏方案已被用户否决，不作为实现方向。

已选方案：用户选择 A「随手翻翻」。定稿规格见 [随手翻翻页头设计](reader-header-browse-design.md)。B、C、D 保留为未选备选，不自动组合进本次设计。

这里的游戏性指用户愿意探索、点击后有明确回应、推荐可以轻松更换，有一点发现内容的惊喜；不增加规则、关卡、对错、输赢、答题、倒计时或通关流程。页头不承担剧情解说，不展示关键事件、人物身份、线索、反转或结局。

## A. 随手翻翻（用户已选）

页头文案（用户已选定）：“这段脑洞，换你会怎么演？”

沿用现有封面区域，叠放两三张真实故事封面，露出可以探索的边缘；悬停时当前封面轻微展开，呈现题材与一句不涉及情节的观看口味，例如“有点怪，有点好笑”。点击进入真实内容；若有经人工审核的不剧透动态封面，可在封面区域预览。触屏提供明确的点击入口，不依赖悬停。

趣味来自封面之间的探索与发现，视觉主体仍是故事内容。只展示真实作品与可用素材，不将假视频放进封面。

## B. 随便逛逛

页头文案：“今天想看点不一样的？”

提供三个轻入口：“有点离谱”“轻松一点”“随便看看”。点击后直接调整下方目录，选中项与结果平顺更新。它们是浏览入口，不是需要完成的性格测试；目录一直可以直接使用。

趣味来自自选与即时回应。按实际标签和内容编辑分类，无匹配时如实显示，不制造推荐结果。

## C. 替你挑一部

页头文案：“选不出来？这部先看看。”

页头只推荐一个真实作品，展示封面、题材与实际时长（有成片时）。主入口为“打开看看”，旁边留“换一部”。切换推荐采用一次短滑动/淡入，完整信息立即可读；不做抽签、开箱或老虎机动画。

趣味来自低成本试探和可以反复换片的惊喜。推荐文案不讲情节，不编造评分、热度或“与你匹配”的依据。

## D. 幕后偷看

页头文案：“这张画，后来动了。”

用同一真实作品的制作画面与对应动态片段做轻量对照。拖动或点按可看到静态画面转为动态，随时停止。片段只展示美术、光影、环境或无剧情泄露的动作，并由作者提前审核。

趣味来自探索静态画面如何成为视频，也能直观展示项目能力。没有同源静态素材和成片时不启用这一方案；不让评委先阅读流程说明，也不声称现场生成。

## 共同原则

- 标题是自然邀请，旁边立即有可探索的内容；不把原标语替换成另一条孤立大标语。
- 原页面配色、字体气质与目录卡片保留；本轮只决定页头内容组织和交互，不改版式体系。
- 动效响应用户操作，约 150–220ms；不自动轮播抢注意力，不强迫等待文字逐字出现。
- 提供真实的题材、片长、制作状态等选择信息，不展示谜底或用剧情问答诱导剧透。
- 去目录、打开作品始终直接可达，趣味交互不会变成观看门槛。
- 当前优先推荐 A；若已有合适且无剧透的同源素材，D 可作为更突出技术效果的备选。
- 候选尚未选定，不继续制作新页面或替换现有应用。
