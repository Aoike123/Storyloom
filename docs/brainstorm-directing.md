# 脑洞题材导演与分镜规范 1.0

适用范围：含“脑洞”标签的已保存知乎故事；其他标签暂不启用专用流程。本规范以影视前期制作的通用方法作为依据，是项目的制作规范，不是行业认证。成片仍需导演、剪辑和声音审核。

## 核心方法

脑洞不是固定类型片，也不等于密集反转。先提炼“如果某个常识被改变，会怎样”的核心假设，再说明规则、限制、代价及其对人物目标的影响。其他原始标签作为故事语境保留，不能把甜宠脑洞统一拍成恐怖片。

导演阐述必须回答：人物想要什么、特殊规则如何阻碍或帮助行动、观众在什么时候理解规则、人物选择造成什么后果。规则必须附可定位的原文依据。正文未提供完整结局时，只设计可用片段，不编造作者终局。

## 三阶段交付

1. 导演阐述：核心假设、戏剧问题、人物目标、规则及逐字依据、改编范围、视觉和信息策略、未知边界。
2. 4–8 镜短场景分镜：镜号、场次、叙事功能、原文依据、主要动作、景别、机位、构图、调度、入出状态、观众与角色所知、暂缓揭示、铺垫引用、时长、对白、声音、剪辑、资产、首帧、运动及风险。
3. 独立文本预审：原文与因果、信息揭示、连续性、剪辑可用性、生产可行性。再由操作者逐镜确认并写明问题处理意见。修改分镜会使旧预审失效，需要重新人工批准。

三次 LLM 请求使用不同职责提示，依次保存中间结果；格式和引用错误会停止后续步骤。它们不是独立人类专家意见，不保证输出无误。任务中断不自动重复收费。

## 镜头语言与剪辑要求

- 每镜一个主要叙事任务、动作与运镜意图；景别改变应服务空间、信息或情绪，不机械循环远中近。
- 清楚交代空间、视线和动作方向；轴线可以有意改变，但应说明中性镜头、人物运动或重新建立空间的过渡。
- 建立镜头、人物反应和关键道具插入应服务剪辑覆盖；不能只做一串人物特写。
- 铺垫先于揭示。`reveal` 与 `payoff` 必须在 `setup_ids` 引用前序镜号；首次建立规则或首次发现异常应标为 `hook`、`setup`、`rule` 或 `escalation`。若入场衔接已明确写出“承接 Sxx”但结构字段漏填，系统只同步这项明确引用，不自行猜测故事因果。
- 镜头默认按 `source_ref` 的 P 编号非递减排列。发现顺序倒退时不自动重排，因为重排还会改变铺垫、转场和动作衔接；系统应把具体倒退镜号交给当前节点重新生成。
- 声音分对白/旁白、环境声、动作音效与音乐；需要时设计声音提前进入或延续到下一镜。音轨设计不等于已经合成。
- 剪辑时长可短于 5 秒；H3 Max 素材生成时长为 5–15 秒，不能用供应商最小时长强迫每个成片镜头都拖长。实际裁切点须看成片后标注。
- 静态首帧与运动描述分离；字幕和规则面板交给后期。复杂多人交互、抓握、遮挡、镜面等必须说明拆镜或替代拍法。
- 资产需求不意味着角色一致性已解决；Z-Image 文生图不是参考图编辑。人物锁定需要进一步的资产绑定和视觉审核。

## 程序检查与人工检查的边界

程序检查镜号唯一、原文引用存在、回收引用前序铺垫、生成时长范围和剪辑时长不超过素材。人物动机、镜头审美、穿帮及反转是否成立由模型预审和人工审核评估，不能靠字符串验证保证。

批准后的分镜由制作节点直接使用已审核的项目参考图发起 MiniMax 参考视频任务，保存导演版本、镜号、构图与运动说明、参考图版本和素材时长。流程不生成关键帧或任何中间改图。此版本尚未自动配音、字幕合成和发布完整原版，也尚未把导演规则接入读者任意暂停改写。
