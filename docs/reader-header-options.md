# 读者主页页头：五个候选方案

> 已被后续澄清替代。用户所说的游戏性指探索感、参与感与操作趣味，不是独立小游戏；页头用于吸引评委且不得剧透。当前有效候选见 [页头吸引力与探索感方案](reader-header-invitation-options.md)。本文件不作为当前实施依据。

状态：待选择的设计方案。保留当前选择页的配色、字体气质、目录卡片与整体布局。只调整现有大标语所在的页头区域；仍沿用动效与交互优化方案，不恢复此前已撤回的视觉重设计。

共同调整：去掉页头的英文品牌宣言；把标题缩为桌面 32–40px、手机 26–30px；文字给出一个具体故事信息或可立即参与的动作。品牌名留在导航，不在首屏反复自我介绍。页头约 260–340px，优先让下方目录尽早出现。下列剧情与对话为原创设计示例，未绑定知乎原著。

## A. 随手挑：今天想看点什么？

- 小字：挑个口味就行
- 标题：今天想看点什么？
- 辅助信息：想轻松一点，还是想被吓一下？
- 选项：笑一下 / 来个反转 / 有点吓人 / 随便看看
- 交互：点击即更新下方故事筛选，已选按钮轻微填色；不额外要求点击确认。保持当前选择页的目录结构。
- 动效：选中反馈约 160ms，结果约 200ms 重排。连续选择只执行最新的一次，不播放额外开场动画。
- 适合：降低挑选门槛、目录内容较丰富时。
- 条件：根据真实标签与简介匹配；某类没有故事时明确显示暂无匹配，不编造结果。偏好只表示本次选择，不包装为人格测试。

## B. 故事钩子：开门，还是不开？

- 小字：先给你看个开头
- 标题：门外的人，为什么和我声音一样？
- 正文：我刚准备开门，手机收到一条自己发来的消息：别开。
- 主按钮：然后呢？
- 次入口：换个开头
- 布局：沿用页头左右构图，左侧放具体悬念，右侧把“别开。”呈现为短消息或一张与故事对应的封面。删除原来的装饰性口号。
- 交互：主按钮直接打开对应作品；有成片进入观看，没有成片明确进入原文。换开头只更换该推荐区域，不刷新全页或自动轮播。
- 动效：更换开头时短淡出/上移 4px，再呈现新文字；容器高度保持稳定。完整句子一次出现，不逐字吊着用户等待。
- 适合：最想让评委立即对某个故事好奇时。首选方向。
- 条件：正式文案需从对应原文与已发布视频中人工确认，只呈现开场信息，不冒充原文引用、不泄露结局。示例不应直接冠以某位作者姓名。

## C. 抽个脑洞：选不出来？抽一个。

- 小字：不知道看什么也没关系
- 标题：选不出来？抽一个。
- 辅助信息：抽到不喜欢的，就再换一个。
- 主按钮：抽个脑洞
- 结果：展示真实故事标题、两项题材标签及“看看这个 / 再抽一次”。
- 布局：左侧简短邀请，右侧一张便签或封面，沿用当前绿色与纸感，不设计老虎机、开箱光效或抽奖奖品。
- 动效：点击后用一次约 220ms 的轻翻卡或替换反馈揭晓结果；没有人工制造的等待。减少动态效果时立即替换。
- 适合：不想花时间挑选的人；也适合放在 B/A 旁边作为一个轻入口。
- 条件：从当前真实可见目录里选取，优先可播放条目，连续两次尽量不重复；没有作品时显示真实空状态。随机结果不称为 AI 专属推荐。

## D. 先选一下：主角又要开那扇门了。

- 小字：换你在现场
- 标题：主角又要开那扇门了。你呢？
- 选项：先拦一下 / 让他开，我躲远点 / 我先走了
- 点击后的单句反馈示例：你是懂保持距离的。
- 下一步：找个故事看看
- 布局：标题与三个文本选项占据当前页头，不创建额外登录、测验或确认步骤。
- 动效：选中项轻微压下再恢复，反馈原位出现；其他选项保持可用，允许改选。
- 适合：希望访客第一秒就能点点东西，强调轻松参与。
- 取舍：比其他方案多一个小动作，仍须保留下方目录和直接浏览入口，不能成为强制引导。
- 条件：明确它是开场小游戏。无真实统计时不显示“多少人和你一样”；当前没有视频改写能力时不称为“你已改变剧情”。如果对应具体作品，题目只引用开场情境。

## E. 先看一段：先看几秒，再决定。

- 小字：可以先看一小段
- 标题：先看几秒，再决定。
- 信息示例：雨夜的站台上，她突然回头了。
- 主按钮：看 8 秒
- 次入口：还有别的吗
- 右侧：真实预览画面、实际时长、题材和可用音轨提示。演示稿使用项目已有的 8 秒样片，不代表已发布作品。
- 交互：用户点击后就地播放，不跳页；播放结束提供完整作品入口（仅真实存在时）和换一段。允许随时跳过进入目录。
- 动效：点击后播放图标短淡出，视频区域尺寸不变；预览无需循环，换一段时先保留封面再切换。
- 适合：最重视视频呈现、希望先让画面说话的竞赛展示。
- 条件：至少准备一段真实、可稳定播放的样片；预览来自对应成片，不用不相关画面包装作品。没有成片时选 B 或 A，不制造“立即观看”的假入口。实际时长动态读取，不固定写 8 秒。

## 推荐与选型

- 想让首页像有人递来一个有意思的故事：选 B。
- 想让评委最快看见视频表现：选 E。
- 想让读者最容易找到喜欢的题材：选 A。
- 想更轻松、愿意点第二次：选 C。
- 想强调参与感：选 D，但保持完全可跳过。

优先推荐 B 或 E。B 可以在对应作品有成片时把“然后呢？”接到就地短预览；C 可作为一个次入口。不要把五套功能都塞进同一页头。

本轮可点击示意仅用于比较内容语气与交互，不调用项目接口、不发布作品。正式实现后仍按既有方案验收快速点击、页面位置恢复、布局稳定、键盘操作与减少动态效果。
