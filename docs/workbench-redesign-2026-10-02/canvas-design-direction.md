# 画布优先设计方向

版本：0.2 · 2026-10-03 · 状态：空间骨架，详细设计按[任务骨架](design-task-skeleton.md)逐项展开

本文件定义当前空间方向，取代固定三列和「叙事画布／章节编排」两套布局。它不代表各画布交互已经定稿，也不代表功能已经实现。[设计规范](design-spec.md)中的唯一归属、准确版本、审核和历史快照规则继续有效。

## 1. 空间骨架

```text
┌────────────────────────────────────────────────────────────────┐
│ 叙间 / 项目名                                 搜索  任务  主题 │
│ 故事     制作     素材     发布                                 │
├────────────────────────────────────────────────────────────────┤
│ 当前范围 / 对象路径                                            │
│                                                                │
│             无 限 画 布 · 占 据 主 体 空 间                     │
│                                                                │
│   内容分组、对象卡片、镜头、素材共用关系直接在画布中组织         │
│   平移 / 缩放 / 拖拽 / 分层进入                                 │
│                                                                │
│                 [查看、编辑、范围或任务工具按需打开]            │
│                                                                │
│ 画布工具                                             视野控制 │
└────────────────────────────────────────────────────────────────┘
```

这是职责与空间示意，不锁定像素、面板方向或详细控件。D01 决定顶栏与工具的具体形态，D02 决定手势及视野规则。画布铺满顶部导航之外的工作区域，不设置一块狭窄的居中预览，也不保留左右常驻列。

- **顶部保留固定空间**：故事、制作、素材、发布来自项目的稳定分支，不是六个生成步骤。运行节点和任务记录不再变成一级导航。
- **画布组织自由内容**：原文／稿件、篇章／场／镜头、身份／服装／场景、发布记录按各自工作模式组织。自由摆放不改变真实归属或叙事顺序。
- **工具依附当前任务**：对象编辑、引用选择、范围操作、队列和历史按需出现，无操作时不占固定列。面板打开、遮挡处理与焦点返回待 D01 设计。
- **定位能力重新设计**：顶部切换、真实路径、画布分层、搜索与定位协作；是否需要小地图或按需大纲由 D02 决定，不把旧左树直接搬回来。

## 2. 四个画布的职责

| 顶部空间 | 主要对象 | 初步工作模式 | 调度设计任务 |
| --- | --- | --- | --- |
| 故事 | 不可变原文、原文章节、调整草稿、采用稿 | 阅读与追溯 → 范围预处理 → 差异比较 → 保存／采用 | D03 |
| 制作 | 可选篇章／集、场、镜头与制作产物 | 结构编排 → 当前场／镜头制作 → 审片；局部模式形态待设计 | D04、D06 |
| 素材 | 人物身份、所属服装、物理场景及准确版本 | 组织素材 → 查看版本与共用位置 → 定位／指定范围采用 | D05 |
| 发布 | 本次候选范围、就绪项、不可变发布记录 | 检查范围 → 创建新发布 → 回看历史 | D07 |

各画布共用交互基础，但不强行共用一种卡片和操作模式。故事强调文本与差异，制作强调层级与衔接，素材强调准确版本与共用，发布强调范围与不可变快照。具体默认布局、手势、任务结果落点按任务逐项确定。

## 3. 状态与调度的共同边界

- 归属树是唯一业务权威；空间标签与画布只展示同一套对象。镜头仍属于场，服装仍属于人物；版本切换不复制节点。
- 当前空间至多一个正在查看的对象；范围多选是另一种显式状态，不能冒充审核。各空间可记住视野与返回上下文，具体保存粒度待 D01／D02 确定。
- 自由摆卡、平移、缩放属于视图偏好；结构编辑和引用采用有明确目标与提交边界，不从坐标自动推断父级、顺序或版本。
- 素材关系表示准确版本的真实使用位置；场计划、镜头绑定、历史发布分别展示。素材到使用位置、使用位置到素材均能返回原上下文。
- 创建任务时冻结目标范围、输入版本与依赖；结果归属发起对象及对应版本。后台完成不抢焦点，迟到结果不覆盖当前版本；具体队列与结果界面由 D06 设计。
- 保存、确认、生成、采用、发布分开。任务成功不表示作者审核通过，采用新素材版本不自动改写已有引用，历史发布不因当前树移动而变化。
- 亮色延续当前工作台，暗色延续主页；按钮与表单共享语义和几何规格。详细卡片与动效在工作模式明确后收敛。

## 4. 放弃的布局约束与保留的能力

旧三列栅格、常驻树列、常驻对象编辑列、独立「章节编排」方案和旧 author 页面堆叠结构不再作为新设计约束。单场聚焦、准确路径、任务恢复、版本审核、素材引用等能力保留，重新放入画布的局部模式与按需工具。

正式归属、原文保护、素材规范、变更影响、发布快照和服务端校验仍依照[设计规范](design-spec.md)。布局可以重做，不能用前端卡片摆放替代这些契约。
