# 画布优先设计方向

版本：1.2 · 2026-10-03 · 状态：切换片段驱动画布职能，任务持续运行；来源连线的细化边界待流程讨论

本文件定义当前空间方向，取代固定三列和「叙事画布／章节编排」两套布局。它不代表各画布交互已经定稿，也不代表功能已经实现。[设计规范](design-spec.md)中的唯一归属、准确版本、审核和历史快照规则继续有效。

## 1. 空间骨架

```text
┌────────────────────────────────────────────────────────────────┐
│ 叙间 / 项目名                                 搜索  任务  主题 │
│ 当前工作标签…（数量、名称与片段范围的呈现方式待定）             │
├──────────────────┬──────────────────────────────────┬────────┤
│ 故事来源区       │ 当前范围 / 对象路径              │ 右工具 │
│ 原文 / 片段      │                                  │ 属性   │
│                  │    当 前 任 务 画 布             │ 引用   │
│ 全文阅读与选取   │                                  │        │
│                  │    原文范围与工作对象局部连线    │ 任务   │
│ 高亮和片段进度   │    平移 / 缩放 / 自由排布        │ 定位   │
│                  │                                  │        │
│                  │    上下文面板按需展开、关闭      │        │
│                  │                       视野控制   │        │
└──────────────────┴──────────────────────────────────┴────────┘
```

这是最新工作模式示意。左侧是贯穿项目的故事全文来源区，提供原文和已切分片段两种视图；正常工作时承担阅读、选取与来源对照，在剧本、资产等标签中与当前画布联动。进入切分／裁减任务时，右侧画布承担片段拆分、合并和裁减，详见第 7、9 节。全局项目树与旧工具轨不恢复；右侧仍保留按需上下文区域，不设独立版本入口。成片的主体是剪辑工作区。本期正式开发仍仅覆盖[框架计划](implementation-plan.md)，本轮工作模式不自动扩大实施范围。

- **顶部导航随工作模式设计**：此前「故事、制作、素材、成片」是框架展示中的暂定划分，数量、名称与层级不再作为固定约束。故事总控负责原文切分和项目进度；点击确认片段倾向进入大标签，具体承载方式继续设计。剧本、分镜、资源生成和剪辑的职责保留，最终如何安排工作标签另行讨论。
- **多场画布默认展开**：制作按场整齐排列多个镜头，素材按资源排列节点。分组直接在画布中表达，不设置场次选择器或常驻图层索引。
- **画布组织自由内容**：稿件、篇章／场／镜头、素材需求、独立资源按当前任务组织。自由摆放不改变真实归属或叙事顺序；成片的时间轴属于剪辑编排，不采用自由画布坐标。
- **阅读视图、片段选择与执行任务分开**：原文／片段是左侧的阅读组织方式；用户切换到另一个片段时，右侧必须跟随目标片段切换对应的工作状态和职能。正在排队或运行的任务继续执行，不因画布切换中断；用户可从项目任务队列快速回到原片段的工作位置。左侧全文区的宽度、展开与收起继续设计。
- **工具依附当前任务**：右侧承载对象上下文，暂留属性、引用、任务和定位入口，不设版本入口。面板展开、关闭及内容插槽属于框架；具体操作规则待讨论。
- **定位能力重新设计**：顶部切换、真实路径、画布分层、搜索与定位协作；是否需要小地图或按需大纲由 D02 决定，不把旧左树直接搬回来。
- **跨标签切换由用户主动操作**：查找结果、引用素材或使用位置默认在当前工作区查看详情。用户点击确认好的故事片段，可以主动进入对应的大标签，这是当前倾向，尚未锁定标签的名称与组织方式。显式切换后恢复各工作区的范围与视野；任务完成和 AI 回答不自动跳转。

## 2. 工作职责与暂定承载

以下是当前工作职责的划分，导航数量与页面对应关系继续讨论。可按实际工作模式拆分、合并或重命名，避免用原四标签限制后续设计。

| 工作职责 | 主要对象 | 初步工作模式 | 调度设计任务 |
| --- | --- | --- | --- |
| 故事总控与来源 | 可编辑故事正文、留存的导入原稿、原文片段、忠实图谱、节奏要求、产物覆盖与项目进度 | 项目左侧切换原文／片段视图，选择故事范围并与当前任务联动；切分／裁减任务在右侧画布处理片段；支持 AI 提问 | D03 |
| 剧本与分镜制作 | 片段对应的剧本、多场分镜、人物和场景分配、素材输入、镜头衔接、视频片段 | 根据原文片段改编剧本 → 创建分镜并细化资源绑定 → 素材就绪后生成片段 | D04、D05a、D05b、D06a |
| 素材管理 | 生成条件、参考输入、任务结果及人物／服装／场景等资源版本 | 生成或提供素材 → 比较和修改结果 → 选用准确版本；使用位置作为辅助信息 | D05c |
| 成片剪辑与交付 | 已审核镜头片段、剪辑实例、多轨时间轴、固定交付版本 | 自由选用与剪辑 → 后处理 → 确认同一版本 → 发布／导出 | D06b、D06c、D07 |

故事拥有原文片段结构、原文对应关系与节奏要求；制作拥有剧本、分镜、资源分配与镜头衔接。原始故事对应多个故事片段，每个故事片段对应一个剧本，剧本对应多个分镜，分镜根据绑定资源生成视频片段，成片通过选择和剪辑引用这些视频片段。图谱忠实记录原文对象、关系与出处，未明确的信息保留不确定性，不承担额外的叙事创作。成片允许片段重排、重复取用和交叉编排，不反写制作中的镜头结构；每次取用是独立剪辑实例。

资源从剧本开始建立引用，随分镜逐渐细化；同一人物或场景的共用关系保留。细化内容不要求直接连回原文，其资产或制作对象的归属与引用继续记录；哪些内容属于细化、哪些需要原文对应关系，在具体流程中再定。素材负责提供、生成和修改资源；正式镜头生成使用就绪的准确版本。提示词随生成过程保存，不成为项目主层级。用户切换片段时画布跟随，后台任务完成不自动抢占当前画布。

故事总控默认按原文顺序组织片段，分别呈现产物数量与原文覆盖程度；两者不相互代替。自然语言查询读取项目状态并可定位相关片段。用户调整尚未生成视频的片段时，相关剧本和分镜标记为待更新；共用资产及已有视频的原文关联继续保留。节奏调整在故事空间表达意图，由后续制作环节落实；具体变更、覆盖计算及交互规则继续讨论。

以上为最新职责结论；现有只读框架及适配模型的迁移另行安排，不扩大当前 F0–F4 的实现范围。

## 3. 状态与调度的共同边界

- 归属树是唯一业务权威；空间标签与画布只展示同一套对象。镜头仍属于场，服装仍属于人物；版本切换不复制节点。
- 当前空间至多一个正在查看的对象；范围多选是另一种显式状态，不能冒充审核。各空间可记住视野与返回上下文，具体保存粒度待 D01／D02 确定。
- 自由摆卡、平移、缩放属于视图偏好；结构编辑和引用采用有明确目标与提交边界，不从坐标自动推断父级、顺序或版本。
- 素材关系表示准确版本的真实使用位置；场计划、镜头绑定、历史发布分别展示。素材到使用位置、使用位置到素材均能返回原上下文。
- 多项输入直接记录在镜头分配中：资源类型、用途与作用对象分别记录。人物／服装／场景／动作及运镜参考使用同一套可编辑输入列表，不暴露制作组合实体。默认不显示素材连线，点击镜头展开准确关系，再次点击收起，换镜头时切换局部关系；不累积全局网。镜头顺序可用轻量衔接线常驻表达。
- 创建任务时冻结目标范围、输入版本与依赖；结果归属发起对象及对应版本。后台完成不抢焦点，迟到结果不覆盖当前版本；具体队列与结果界面由 D06 设计。
- 任务队列属于项目，独立于当前查看的片段。切换片段或标签不取消、重启或重新归属已有任务；结果仍回到发起它的片段和对象。队列项可定位原片段、任务对应的工作画布及结果，方便主动找回；具体列表展示继续设计。
- 保存、确认、生成、采用、发布分开。任务成功不表示作者审核通过，采用新素材版本不自动改写已有引用，历史发布不因当前树移动而变化。
- 剪辑实例固定源镜头片段版本与入／出点，并记录轨道、位置、速度、声音和效果。发布与导出绑定同一个确认的剪辑版本及输出规格；重试交付不重新采用草稿或重新生成镜头。
- 亮色延续当前工作台，暗色延续主页；按钮与表单共享语义和几何规格。详细卡片与动效在工作模式明确后收敛。

## 4. 放弃的布局约束与保留的能力

旧三列页面堆叠、常驻完整项目树、左侧工具轨、独立版本工具、独立「章节编排」方案和旧 author 页面结构不再作为新设计约束。最新设计由项目级故事来源区、主体任务画布与按需上下文区域构成；左侧正文与来源对照是用户新提出的工作内容。准确路径、任务恢复、版本数据和引用能力保留。制作、素材不以单场选择限制画布。

正式归属、原文保护、素材规范、变更影响、发布快照和服务端校验仍依照[设计规范](design-spec.md)。布局可以重做，不能用前端卡片摆放替代这些契约。

## 5. 当前交付与下一步

当前 D00 完成，D01 已有明暗样式展示。制作画布以三组场、每组三个镜头展示整齐排列和自由拖动；右侧可体验画面意图、衔接及素材输入的示例编辑。素材展示生成条件与版本入口，成片保留剪辑壳。真实素材与片段生成、分镜新增拆合、正式保存、兼容校验、影响采用及交付仍按拆分任务推进，不标记产品实现完成。

布局参考 Figma 的主体画布和[右侧对象属性面板](https://help.figma.com/hc/en-us/articles/360039832014-Design-prototype-and-explore-layer-properties-in-the-right-sidebar)，不照搬左侧索引；人物／服装配对、准确版本引用与制作调度是叙间自己的领域设计。

验证仅做当前样式的必要走查，不执行全量测试或等待生产任务。开发安排到框架验收为止；镜头、素材、生成、审核、剪辑与交付的操作确认后再补下一阶段计划。

## 6. 项目入口页

入口从「原作导入与故事市场」调整为「查看他人发布项目与新建项目」。浏览对象为公开项目，一个项目可以包含多个已发布成片；新建项目作为固定主操作。原文添加与切分属于项目内的故事总控。

- **主体**：公开项目列表，展示封面、项目名称、创作者与简要介绍；点击后查看该项目公开介绍和已发布成片。公开卡片按项目组织，不将同一项目的多个成片拆成多个项目卡片。
- **主操作**：顶栏保留统一的「新建项目」按钮；先建立项目，再进入故事总控添加原始故事。项目创建不会从公开项目卡片点击隐式触发。
- **个人项目入口**：暂定以同级「我的项目」入口恢复已有项目，不把草稿混入公开列表；位置与展示细节待讨论。
- **公开边界**：入口展示已发布项目内容。原文、图谱、剧本、分镜与资产是否公开另行讨论，不因项目发布默认全部公开。
- **空状态**：没有公开项目时仍能新建自己的项目；公开列表为空与用户没有项目是两个独立状态。
- **视觉**：双主题沿用整站配色，取消大幅导入宣传区和重复导入按钮。项目封面成为浏览主体，统一控件几何规格、主次动作与返回路径。

当前仅提供入口布局和浏览／创建路径的讨论稿；命名、公开内容范围、新建细节、登录与权限及业务接口仍待讨论，不宣称产品逻辑已实现。展示稿位于同一对话的项目入口设计预览。

## 7. 故事总控：正文、片段与进度标签

2026-10-03 最新设想：故事允许修改、增补和结构变动；左侧变为贯穿项目的全文来源区，提供「原文」和「故事片段」两种视图，与不同任务标签联动。正常工作时承担原文边栏和范围选择器，进行切分／裁减任务时右侧画布恢复片段编辑职能。导入原稿作为历史依据留存，前台不增加第二套常驻稿件区或独立版本工具。

```text
┌────────────────────────────────────────────────────────────┐
│ 项目名称       当前任务大标签…（数量与名称待定）            │
├───────────────────────┬────────────────────────────────────┤
│ 故事来源 · 原文/片段  │ 当前任务画布                       │
│                       │                                    │
│ 高亮范围：片段 01 ────┼── 片段 01 · 已确认 · 视频 3/8      │
│                       │                                    │
│ 高亮范围：片段 02 ────┼── 片段 02 · 待确认                 │
│                       │                                    │
│ 选取一段文字          │ 确认片段 → 进入片段工作标签        │
│ → 建立候选片段        │                                    │
│ 阅读／选择／来源对照 │ 剧本、资产或切分／裁减按任务切换   │
│                       │ AI 提问／建议入口                  │
└───────────────────────┴────────────────────────────────────┘
```

上图是工作模式示意，数字为示例，宽度、AI 面板位置和具体视觉仍待设计。

- **两种来源视图**：原文视图连续展示全文；片段视图按用户／AI 已切分的边界组织故事正文，附片段标识与进度。未切分内容保留可见，具体呈现待设计。两种视图共享正文和来源对应关系，不维护两份独立故事。
- **切换片段与任务持续**：左侧原文／片段视图用于阅读和选择；同一片段内查看来源关系与修改正文是不同操作。切换到另一片段时，右侧跟随其工作状态和职能切换，原排队或执行任务继续。任务范围、输入和结果归属保留，用户可从任务队列主动返回。
- **正文与片段对应**：每个片段保留稳定标识和原文范围。正文高亮与进度标签使用同一标识；当前选中范围增强高亮并显示局部引导关系，长故事不铺满全部连线。
- **手动切分**：用户选择故事内容后建立候选片段，查看范围并确认。选取文字、创建候选和确认片段是不同动作；候选不被当作已经完成制作的片段。
- **修改与增补**：当前正文支持编辑和增加内容，片段可拆合、调整范围及节奏。修改后的文本对应关系需要同步，已有视频保留生成时的文本依据；受影响的下游内容标记待更新，不静默替换已有产物。具体同步和部分已生成片段的调整规则待讨论。
- **进度标签**：显示片段名称、确认／制作阶段和关键完成量；展开后查看关联剧本、分镜、资产、视频与成片。已生成视频、成片完成和发布分别表达，不用一个百分比代替全部状态。
- **AI 提问**：支持自由提问，不限定为预设问题；故事内容、原文关系、切分建议与项目进度是主要示例。根据当前选取范围或当前片段回答，并给出原文出处或对应项目对象；全故事问题使用全项目范围。AI 可以提出修改或切分方案，确认好的片段仍由明确操作产生。
- **进入与返回**：用户切换片段时进入目标片段对应的画布工作状态，具体大标签呈现仍待设计。切换时保留正文阅读位置、来源视图和各片段的工作上下文。任务队列提供快速找回：点击任务定位其原片段与工作画布／结果。AI 回答和后台完成只更新状态，不自动切走用户当前查看的片段。

**待确认**：大标签如何呈现片段对应的工作状态、全文区的宽度与展开、任务队列的展示与返回位置、正文修改保存、范围重叠与部分已生成内容的处理、AI 写入及来源映射编辑，以及各具体流程中的细化边界。此轮只设计来源区、画布切换与持续任务的协作，不展开完整制作操作。

## 8. 大标签的开放方向

用户已明确原四个大标签不固定；进入确认片段倾向使用大标签，但尚未想定完整导航。

此前「每个确认片段打开一个大标签」仍是候选方案。最新设想让左侧承担原文／片段的阅读和选择，大标签承载工作任务；片段范围可以作为工作上下文，不必通过持续增加大标签表达。具体导航、片段进入方式，以及跨片段素材与成片是否设置独立项目级工作区仍待讨论，原四标签和片段标签方案均不固定。

这是候选方案，尚未作为开发契约。片段内的剧本、分镜及生成操作和层级继续逐步讨论；现有四标签框架与历史展示记录不因本轮讨论自动重构。

## 9. 不同任务中的来源联动

| 当前任务 | 左侧故事来源区 | 右侧主要工作 | 连线表达 |
| --- | --- | --- | --- |
| 切分／裁减 | 选取原文或已有片段，查看范围与进度 | 建立候选片段、调整边界、拆合与裁减 | 原文范围到片段，保留出处 |
| 剧本 | 阅读并选取原文中的人物行动和语言 | 剧本动作、对白及改编结果 | 原文内容到对应剧本内容，表达保留、转写、合并等实际变化 |
| 资产 | 选择原文出现的人物、服装、场景、道具等对象或其出现位置 | 资源需求、已提供／已生成素材及结果修改 | 原文对象／出现位置到实际生产资产；细化内容不要求逐项连回原文 |

- **局部双向关系**：选择来源范围时突出当前画布上的相关对象；选择画布对象时定位其来源。连线只展开当前选择的关系，避免全文到全部产物的全局网。关闭连线不删除对应关系，浏览和修改关系分开。
- **共用资产与细化边界**：同一对象的多处原文出现可以关联同一资产。细化内容不要求直接连回原文，保留其资产／制作对象归属与引用即可；具体分类在对应流程中讨论，不提前给所有属性套用来源连线。正式生成需求与镜头输入仍从剧本开始绑定并逐层细化。
- **来源与产物状态分开**：原文提到了某项资产，不表示素材已经生产；有剧本对应，不表示已有视频。显示对应对象的实际状态，不从连线存在推断制作完成。
- **变化可追溯**：当前故事正文改变时保留历史产物所依据的文本与关系，提示受影响内容待更新；来源查看与局部连线浏览不改写数据。切换片段改变当前画布上下文，执行任务和结果归属继续保持。

此表确定协作方向，连线粒度、差异展示方式、来源映射的人工修正与具体交互继续设计。
