# 画布优先设计方向

版本：0.5 · 2026-10-03 · 状态：空间骨架与样式展示，详细设计按[任务骨架](design-task-skeleton.md)逐项展开

本文件定义当前空间方向，取代固定三列和「叙事画布／章节编排」两套布局。它不代表各画布交互已经定稿，也不代表功能已经实现。[设计规范](design-spec.md)中的唯一归属、准确版本、审核和历史快照规则继续有效。

## 1. 空间骨架

```text
┌────────────────────────────────────────────────────────────────┐
│ 叙间 / 项目名                                 搜索  任务  主题 │
│ 故事     制作     素材     成片                                 │
├────────────────────────────────────────────────────────────────┤
│ 左工具 │ 当前范围 / 对象路径                         │ 右工具 │
│ 图层   │                                            │ 属性   │
│ 素材   │      无 限 画 布 · 占 据 主 体 空 间         │ 引用   │
│ 选择   │                                            │ 版本   │
│ 移动   │   内容分组、场、镜头、局部素材引用           │ 任务   │
│        │   平移 / 缩放 / 自由排布 / 分层进入         │ 定位   │
│        │                                            │        │
│        │   两侧索引与对象面板可展开、可收起           │        │
│        │                               视野控制     │        │
└────────────────────────────────────────────────────────────────┘
```

这是画布工作区的空间示意。两侧为类似 Figma 的窄工具轨，索引与属性可展开、可收起；故事、制作和素材以无限画布为主体，成片改用镜头库、预览与时间轴。D01 继续确定上下文与面板规则，D02 决定正式手势与视野契约。

- **顶部保留四个空间**：故事、制作、素材、成片。故事沿「故事处理 → 结构编排」推进；制作沿「预制作 → 镜头引用」推进，以明确的前后步骤表达，不做并列模式选择器。运行节点和任务记录不成为一级导航。
- **画布组织自由内容**：稿件、篇章／场／镜头、素材需求、独立资源按当前任务组织。自由摆放不改变真实归属或叙事顺序；成片的时间轴属于剪辑编排，不采用自由画布坐标。
- **工具依附当前任务**：左侧索引图层、素材并提供画布工具；右侧承载当前对象的属性、引用、版本和任务。收起后仅留窄轨，展开和焦点返回规则待 D01 定稿。
- **定位能力重新设计**：顶部切换、真实路径、画布分层、搜索与定位协作；是否需要小地图或按需大纲由 D02 决定，不把旧左树直接搬回来。
- **跨标签切换由用户主动操作**：点击对象、查找结果、引用素材或使用位置，在当前标签的右侧查看详情，不自动跳到另一个大标签。显式切换后恢复该标签自己的流程步骤、范围与视野；正式返回和未保存编辑规则待 D01 定稿。

## 2. 四个空间的职责

| 顶部空间 | 主要对象 | 初步工作模式 | 调度设计任务 |
| --- | --- | --- | --- |
| 故事 | 不可变原文、草稿、采用稿、篇章／场／镜头结构 | 故事处理遵循已确定的素材约束；产出采用稿，再进入层级、顺序、来源与衔接编排 | D03、D04 |
| 制作 | 分镜素材需求、镜头的准确引用、生成任务及结果 | 预制作确定需求并准备素材，再核对／采用镜头分配；就绪后生成与审核镜头片段 | D05a、D05b、D06a |
| 素材 | 人物、服装、场景、参考视频等独立资源与版本 | 新增／提供／修改资源；按镜头查看上一步已采用的分配结果，点击开合连线 | D05c |
| 成片 | 已审核镜头片段、剪辑实例、多轨时间轴、固定交付版本 | 自由选用与剪辑 → 后处理 → 确认同一版本 → 发布／导出 | D06b、D06c、D07 |

前后步骤职责分开：结构编排不堆素材卡或常驻引用线；镜头引用不编辑篇章层级和叙事顺序。二者读取同一套稳定镜头 ID。成片允许镜头片段重排、重复取用和交叉编排，不反写故事的镜头结构；每次取用是独立剪辑实例。

故事处理产出采用稿，结构编排形成分镜；预制作从分镜整理需求并提供或生成素材，再核对／采用准确镜头引用，生成并审核片段，最后进入剪辑与同版交付。故事处理也可参考已有素材约束，新增细节形成补充需求；前后步骤可显式返回修订，任务完成不自动跳步骤或大标签。

## 3. 状态与调度的共同边界

- 归属树是唯一业务权威；空间标签与画布只展示同一套对象。镜头仍属于场，服装仍属于人物；版本切换不复制节点。
- 当前空间至多一个正在查看的对象；范围多选是另一种显式状态，不能冒充审核。各空间可记住视野与返回上下文，具体保存粒度待 D01／D02 确定。
- 自由摆卡、平移、缩放属于视图偏好；结构编辑和引用采用有明确目标与提交边界，不从坐标自动推断父级、顺序或版本。
- 素材关系表示准确版本的真实使用位置；场计划、镜头绑定、历史发布分别展示。素材到使用位置、使用位置到素材均能返回原上下文。
- 多项输入直接记录在镜头分配中：资源类型、用途与作用对象分别记录。人物／服装／场景／动作及运镜参考使用同一套右侧输入列表，不暴露制作组合实体。默认无连线，点击镜头展开准确素材关系，再次点击收起，换镜头时切换局部关系；不累积全局网，也不为新资源增加工具模式。
- 创建任务时冻结目标范围、输入版本与依赖；结果归属发起对象及对应版本。后台完成不抢焦点，迟到结果不覆盖当前版本；具体队列与结果界面由 D06 设计。
- 保存、确认、生成、采用、发布分开。任务成功不表示作者审核通过，采用新素材版本不自动改写已有引用，历史发布不因当前树移动而变化。
- 剪辑实例固定源镜头片段版本与入／出点，并记录轨道、位置、速度、声音和效果。发布与导出绑定同一个确认的剪辑版本及输出规格；重试交付不重新采用草稿或重新生成镜头。
- 亮色延续当前工作台，暗色延续主页；按钮与表单共享语义和几何规格。详细卡片与动效在工作模式明确后收敛。

## 4. 放弃的布局约束与保留的能力

旧三列页面堆叠、常驻完整项目树、独立「章节编排」方案和旧 author 页面结构不再作为新设计约束。左右工具轨与可收起面板是本轮新的空间选择；单场聚焦、准确路径、任务恢复、版本审核和引用能力保留，放入局部模式与按需工具。

正式归属、原文保护、素材规范、变更影响、发布快照和服务端校验仍依照[设计规范](design-spec.md)。布局可以重做，不能用前端卡片摆放替代这些契约。
