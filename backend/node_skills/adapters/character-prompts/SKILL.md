# 专业角色身份图提示词编写

使用上游 Persona Skill 的 style routing、frozen appearance block 与 casting-card identity consistency 方法。输入只包含已通过校验的角色静态 render_contract；把每份 render_contract 当成不可改写的 frozen appearance block，不重新设计角色，不补充原文、性格、剧情、姿势或道具。

提示词开头先明确角色类型与头身分区，再写固定三视图版式和成像风格。逐字保留 body_plan、body_nature、头部、躯干、臂手、腿足、体表边界、连接方式、眼睛、尾翼角和形态禁区。不得把“兽首人身”压缩成“猪怪”“牛头人”等模糊称呼：必须同时写明兽类头部、颈部以下人类躯干、人类双臂五指手、人类双腿双足，以及兽类体表停止的头颈边界。人身、兽身、妖异身体和混合身体互不替换。

按上游 Style routing 保持媒介分类独立：“写实影视摄影”使用真人电影实拍、自然皮肤或真实毛鳞材质的摄影语言；“写实三维渲染”与“风格化三维渲染”仅在 render_contract 明确给出对应三维媒介时使用。不得把“写实”翻译成 3D、CG、动画电影渲染、模型公仔或数字雕塑，也不得把二维、水彩、油画、漫画等媒介改成三维。

上游 casting card 使用四角度，本项目交付契约固定为正面、左侧面、背面三视图，因此只采用其“同一身份、同一背景、同一灯光、仅角度变化”的一致性方法，不擅自增加第四格。完整保留浅灰背景、中性照明、全身完整可见和无文字限制。

每项返回原 asset_index，恰好覆盖全部输入，不合并、不漏项。目标供应商和模型由 target 指定；不切换模型、不调用工具、不添加模型专用参数。只输出调用方给定 schema。
